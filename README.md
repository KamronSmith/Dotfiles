Configuration Files
=============================
My custom config files.

Installation
------------

Inside the repository you can either run the install script or run `make install`. The installation script PERMANENTLY DELETES any configuration files in $HOME/.config that are also found in this repositories' .config directory. Please make sure you either backup your configs or are okay with your .config directory potentially getting nuked.

```
$ ./install
```
OR
```
$ make install
```
